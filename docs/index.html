AIエージェントの「口約束問題」を完全克服

チャットエージェント（OpenClaw等）が直面する壁と、本システムによる解決アプローチ

一般的なAIチャットの課題

  • 虚偽の進捗報告: 裏でコマンドを実行していないのに「140件完了しました」と口だけで嘘をつく。
  • ブラウザ切断で停止: チャットの返答時しか動かず、画面を閉じると処理が中断する。
  • 巻き戻せない危険: いきなり上書きリネームされ、誤判定時に元のファイル名が分からなくなる。

本システムの解決アーキテクチャ

  • systemd 完全常駐化: systemd-run --user により、切断・スリープ復帰でも自律継続。
  • Vision自動フォールバック: スキャンPDFや文字化けも表紙画像から直接視覚読み取り。
  • Dry-run & ワンタッチRollback: まずCSVで一覧確認し、万一の復元も1秒で可能。

堅牢な処理フロー

テキストとVisionのハイブリッド判定で高速・高精度を実現

1

無関係名の自動検出

すでにタイトルが付いているファイルはスキップし、download や巻号番号などのみを抽出。

2

ハイブリッド解析

テキスト抽出で高速判定。文字化けや画像PDFは自動でGemma 4 Visionに切り替え。

3

SQLite 進捗DB

1ファイル完了ごとにトランザクション記録。途中で止まっても続きから瞬時に再開。

4

安全リネーム & Rollback

CSV確認後に一括反映。同名衝突（_1, _2）を防止し、いつでも元通りに復元可能。

Privacy & Security

🔒 AI生成コードの安全公開・完全匿名化ワークフロー

AIとの対話で作成されたスクリプトから、個人情報・環境パス・コミット履歴を完全消去して公開する手順

1. .gitignore による完全分離

実ファイル名や病名・個人データを含む .sqlite, .csv, .log を除外し、公開用スクリプトのみをクリーンに独立。

2. 絶対パスの相対化

/path/to/private/... などのローカル固有パスを ./data/... などの実行時相対パスに一般化。

3. Git Author 匿名化

GitHub公式の users.noreply.github.com アドレスを設定し、過去コミット履歴も含めて --amend で私用アドレスを完全抹消。

より詳しい手順・チェックリスト・自動監査スクリプト

万が一コミットしてしまった場合の強制上書き（force push）手順なども網羅しています。

💡 AIエージェントに指示するプロンプト

OpenClaw等に依頼する際、ハルシネーションを防ぎ確実に自律実行させるテンプレート

Prompt Template (Markdown) 
【指示】
以下のフォルダにあるPDFを整理・リネームしてください。
対象フォルダ: /パス/to/フォルダ

【厳守ルール】
1. チャットの会話だけで進捗を報告しないでください。必ず bash ツールを使って実際にコードを作成・実行してください。
2. 処理数が多いので、チャットの返答で処理するのではなく、Pythonスクリプトを作成して systemd-run または nohup でバックグラウンド実行してください。
3. いきなりファイルを書き換えず、まずは Dry-run（解析のみ行い、変更前後の対応表を CSV に出力）で実行してください。
4. 処理が途中で止まっても再開できるよう、SQLite や JSON で1ファイルごとに進捗を保存（レジューム対応）してください。
5. 処理を開始したら、現在の進捗（件数と内訳）を確認できる status 用のシェルスクリプトを作成し、その実行コマンドを私に教えてください。

クイックスタート

数行のコマンドで即座にバックグラウンド実行を開始できます

1. リポジトリのクローンと準備

git clone https://github.com/<user>/local-llm-pdf-renamer.git
cd local-llm-pdf-renamer
pip install pymupdf requests

2. バックグラウンド解析の起動（Dry-run）

./scripts/run_papers_batch.sh --dry-run
# 進捗確認
./scripts/status_papers_batch.sh

3. レポート確認後にリネーム適用

python3 scripts/rename_papers.py --apply
# 万が一元に戻す場合: python3 scripts/rename_papers.py --rollback
